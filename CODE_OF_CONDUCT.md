# Code of conduct

## Participation

Everyone participating in this project is expected to treat others with respect.
This applies to issues, pull requests, discussions, reviews and other
project-managed spaces, and when representing the project publicly.

Be constructive, considerate of different experience levels, and open to
technical disagreement. Critique ideas and changes rather than people. Respect
privacy and avoid sharing another person's information without permission.

Harassment, threats, discriminatory insults, unwanted sexual attention,
personal attacks, deliberate disruption and disclosure of private information
are unacceptable.

## Reporting problematic behavior

For problematic GitHub content, open its three-dot menu and select
**Report content**, where available. You can report abuse to GitHub Support.
GitHub also provides an [abuse reporting form](https://support.github.com/contact/report-abuse).

These reports go to GitHub, not automatically to the project maintainer.
Reporting directly to repository administrators is available only where GitHub
supports it and the repository has enabled it. This project does not promise
that this option is available or that GitHub forwards a report to its maintainer.

For instructions and eligibility, see
[GitHub's reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Do not post sensitive allegations, personal information or private evidence in
public issues, pull requests or discussions. No private direct-contact channel
to the maintainer is provided by this document.

Security vulnerabilities use the separate process in [SECURITY.md](SECURITY.md);
private vulnerability reporting is not a channel for conduct complaints.

## Moderation

Maintainers may request changes, remove inappropriate content, close or lock
conversations, or restrict participation using available GitHub controls.
Actions should reflect the nature, severity and repetition of the behavior.
GitHub independently handles reports under its own policies.

This project does not guarantee a response time or a particular outcome.
